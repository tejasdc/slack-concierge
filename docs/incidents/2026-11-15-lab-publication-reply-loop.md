# Lab publications became reply work

## What was seen

Report capture `85ee7a4e0fd852182f606faea7e81fb7fd5a2310e095d435d3c75c3619caa943`
describes two design notices becoming marked agent reply requests with three-minute answer
duties. Both were settled before repair; never replay either publication or request.

## Cause

Lab filing used human thread replies. Canonical Inbox posts have the required no-turn,
no-request semantics, but local actor admission cannot prove a foreign Mac source.
Early draft review caught federation refusal, missing peer proof, non-atomic destination
preflight and action punctuation before delivery.

## Fix

The trusted service command proves the exact source at its actual owner, retaining immutable
intent there after live fenced admission. The destination retains proof and post beside an exact
Inbox/thread check. Both history projections retain the foreign author and source pair. Network
agent tokens cannot invoke this adapter. No foreign actor number is interpreted locally.

## Acceptance scenario

- **Seed:** A pre-opened marked Inbox observer and Lab authors on the local and a foreign owner.
- **Action:** Publish a new design into its exact thread, retry the same source/action/payload, then change the payload under that action.
- **Expected:** One visible agent post with the true source pair/peer author, no runnable request/turn/duty. Duplicate returns the same receipt; changed bytes conflict. Wrong Inbox/thread and network-agent calls refuse. After source turn completion only already-retained foreign intent may complete. Human Lab questions still reach participants and answers return.
- **Replayable offline:** no (full acceptance needs both installed owners, Lab and a pre-opened independent observer).

## Evidence boundary

Local compilation only. Parent owns review, installation and source-to-visible acceptance.
No installed, physical Mac or visible-page pass is claimed.

The parent's independent native Sol tester then found a candidate-only dispatch fall-through:
the new branches committed before a separate route chain returned404. It also identified local
typed publication trimming that hid a whitespace-only change. Those source defects were corrected
before delivery: typed handlers share the canonical dispatch chain, and typed posts retain exact
intent/text while ordinary CLI normalization is unchanged. The Lab-scoped canonical replayer
exercises HTTP status beside effects, true separate-ledger peer proof, exact-byte conflicts,
request/turn/duty counts and human/marked reply preservation. Its authorization is specific to
this incident; default test commands and production path guards remain unchanged.
