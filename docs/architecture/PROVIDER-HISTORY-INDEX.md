# Bounded provider history reads

Claude Code's native session reader follows the transcript graph and compaction rules. Concierge must not recreate those rules from raw JSONL or run that reader inside the single request owner.

The first history request starts one serialized child import and returns `coverage.complete=false` with `history_indexing`. The child uses the native SDK, inserts queued human messages at their native positions, and atomically publishes a separate SQLite snapshot of ordered source rows, message identities, and tool names. It sends no transcript bytes over IPC. The release includes this worker beside the owner bundle. Imports have a 120-second deadline; a failed import is reported as `history_import_failed` with a retry interval. The old snapshot remains readable while a replacement builds.

Pages read only the requested ordinal range; tool detail reads one indexed row. Page cursors pin the snapshot generation and retained-event sequence. A replacement invalidates old cursors, so the consumer must reset to the latest page. The import records the owner's message-event sequence *before* the child starts. The owner merges later retained messages into the indexed baseline by exact message ID. Events written during import are therefore replayed and coalesced instead of being lost.

An append to Claude's file does not itself trigger another full import. A bounded tail check verifies that every new visible message and tool result is represented by a retained owner event and that the transcript remains an append of the same graph. Verified byte positions are remembered for the owner's lifetime. External writes, graph branches, compaction, truncation, missing retained messages, or more than 200 unmerged event versions make coverage incomplete and schedule one background import after the source stabilizes. The page continues serving the last snapshot and retained live messages while preparation runs. This is a freshness contract, not a promise that complex external history is instantly available.

The separate snapshot is derived data; the native transcript and owner event ledger remain authorities. Do not delete either as cache cleanup. Look for `provider_history_imported`, `provider_history_import_failed` and response `coverage` during investigation. A cold page's client must retry on `history_indexing` instead of presenting an empty conversation as complete.
