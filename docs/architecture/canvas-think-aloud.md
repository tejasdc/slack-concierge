# Canvas think-aloud session

Canvas think-aloud is an ordinary continuing Codex session in the writing project chosen by Tejas. The browser and the device speech bridge send only finalized local transcription text as his message. The session owner supplies the board, page, and source input identities beside that message, leaving his words exact in the transcript.

For each checkpoint, the owner tells Codex how to read the visible board, full saved threads, and Reader through Thinkering's private capability socket. Codex can organize a coherent fragment as an agent-attributed proposal, focus or move Canvas objects through the page action door, research, and ask or start other sessions through the ordinary session owner. The page executes visual actions in the open browser; the canonical writer retains workspace changes and their source. Codex does not use the signed-in browser's human-send path to delegate.

The Reader door opens a reading over Canvas, steps through it, and resolves an exact visible passage against the rendered article. The annotation owner stores the agent-attributed highlight with the spoken note and source input; a page action then reveals it in the Reader window. Ambiguous passages are not marked automatically. No generated speech is returned to the microphone path.

This session differs from ambient Canvas voice: that feature is a limited silent Canvas agent using a live socket, while think-aloud is the ordinary Codex project session with its normal tools. A speech checkpoint may be an unfinished thought; the agent is instructed to preserve it as such rather than infer a thesis.
